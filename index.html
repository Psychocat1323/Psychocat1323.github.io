Systems

Systems I've built and fixed

Data saving with DataStore and ProfileStore

Player data that saves and loads reliably: currencies, inventories, progress and daily rewards. I use ProfileStore for session-locked profiles so data isn't lost or duplicated when players switch servers, and I've fixed daily challenge resets so rewards can only be claimed once per day.

DataStoreServiceProfileStoreSession lockingDaily rewards

Obby mechanics

Obstacle course gameplay: checkpoints, kill parts, a run timer, a real-time tracker showing where every player is on the course, and rewards for progress. For moving hazards in multiplayer, the server handles hit detection while each client animates its own copy, so obstacles move smoothly for every player.

CheckpointsTimerPlayer trackerRewardsMoving obstacles

Lobby, subplaces and teleporting

Full game lobbies that send players into the game's subplaces with TeleportService, carrying their data with them between places. Players can queue for matchmaking, join with a party or with friends, or start a private server. The lobby also has an avatar system for customizing characters before a match, daily rewards, and leaderboards.

TeleportServiceSubplacesMatchmaking & queuesParties & friendsPrivate serversAvatar systemDaily rewardsLeaderboards

Shop mechanics and monetization

In-game shops where players spend earned currency or Robux, including Game Passes and Developer Products. Purchases are checked and granted on the server, and the shop UI updates as soon as a purchase goes through.

MarketplaceServiceGame PassesDeveloper ProductsShop UI

Gun mechanics

Weapon systems with shooting, ammo and reloading. The client handles input and effects for instant feedback, and the server validates each shot with raycasts before applying damage, which keeps combat fair.

RaycastingRemoteEventsServer validationWeapon effects
